# 02 — Discrete Math (Haskell)

Revisiting: graph theory, combinatorics, logic, recursion, number theory.

**Tools:** GHC / Stack or Cabal

## Setup

```bash
ghc src/Combinatorics.hs -o combinatorics
./combinatorics
```

Or with `ghci` for interactive exploration:

```bash
ghci src/Combinatorics.hs
```

- [ ] `src/Combinatorics.hs` — permutations, combinations, Pascal's triangle, verify identities numerically
- [ ] `src/Graphs.hs` — BFS/DFS on an adjacency-list graph
- [ ] `src/Logic.hs` — truth-table generator and simplifier for propositional logic
