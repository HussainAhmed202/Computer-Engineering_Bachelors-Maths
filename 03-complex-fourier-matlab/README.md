# 03 — Complex Variables & Fourier Analysis (MATLAB / Octave)

Revisiting: complex functions, conformal mapping, Fourier series, Fourier transform.

**Tools:** MATLAB, or [GNU Octave](https://octave.org/) (free, ~compatible) if no license.

## Setup

```bash
# MATLAB
matlab -batch "run('src/domain_coloring.m')"

# Octave
octave src/domain_coloring.m
```

## Projects

- [ ] `src/domain_coloring.m` — domain coloring visualizer for complex functions (hue = argument, brightness = magnitude)
- [ ] `src/fourier_series.m` — build a Fourier series approximation of a square wave, animate convergence (watch the Gibbs phenomenon appear)
- [ ] `src/fft_audio.m` — load an audio clip, FFT it, plot the frequency spectrum
